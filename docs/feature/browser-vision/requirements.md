# 浏览器视觉需求

状态 Implementation authorized，基于用户全量自主实施指令，不声称本文逐项确认。

| ID | 要求与验收 |
| --- | --- |
| BV-001 | 默认仅 DOM；明确勾选视觉才截图，说明激活目标标签、模型需支持图像；截图仅选定范围当前页 |
| BV-002 | 截图绑定文档、DOM revision、视口/滚动位置及标签；采集前后验证，变化或捕获其他活动页则丢弃，不发送 |
| BV-003 | 自动遮挡输入/编辑区、iframe/媒体、常见凭据文本；用户可在本地矩形补充遮挡并撤回/重置额外区域；像素安全校验，原图不进 UI 或模型 |
| BV-004 | 图像、脱敏文字与接收服务先预览批准；每次动作后的新图重新批准，未批准不发；任务结束/停止释放图像上下文 |
| BV-005 | 支持固定 click_point {imageId,x,y} 视口 CSS 坐标，始终逐次确认，不受自动元素授权豁免；只点可见交互元素/Canvas，遮挡区与敏感目标拒绝 |
| BV-006 | 确认前复核截图文档、revision、viewport、命中元素身份和描述；导航/滚动/遮挡目标/替换节点后拒绝，不自动重试；Canvas 点击派发坐标事件 |
| BV-007 | 每动作后重观察并重截图，模型不能把坐标意图当结果；不启用 debugger 或任意 JS，不伪造 trusted 浏览器输入 |
| BV-008 | 无权限、加载、失效、截图大小超限、模型不支持图片与取消均有错误状态；没有图像时拒绝视觉动作；既有 DOM 模式回归通过 |
| BV-009 | 测试合成页面、临时 Profile；图像与密钥不进入源码/CI/日志/Git；提供一次可选真实服务只读验证，不将 synthetic 当真实模型识别证据 |

边界：当前视口，不是全页/桌面录屏；不可自动识别所有业务机密；Canvas 合成事件并非 trusted 事件，站点要求可信输入时提示手动。iframe/Shadow DOM 操作另属 BA-FRAME。按每张图确认是视觉模式固定策略，未来可增加明确授权的批次隐私策略，本轮不后台默默发新图。
