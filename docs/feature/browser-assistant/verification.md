## 真实扩展场景

1. DOM 观察不包含密码、敏感字段值、隐藏内容或合成密钥，元素变化后旧快照不能写入。
2. 发送预览批准前模型请求数为零；只读总结不会改表单。
3. 内容脚本直接读 storage.local 密钥失败，公开桥接拒绝 apiKey；网页不能调用 assistant API。
4. 旧 AI 请求中的自定义地址/密钥被忽略，只使用后台配置。
5. 只读模型建议写入被拒绝。
6. 确认填写执行一次；重复确认拒绝。
7. 确认提示出现后页面变化，执行失败且没有写入。
8. 选择和点击分别确认；只读滚动可用。
9. 导航后停止模型发送，直到新页面预览再次批准。
10. 停止中断模型；关闭界面停止；新界面显示停止；真实 UI 完成预览→批准→结果。

## 视觉与隐私

- 本地查看 420px 明暗主题与预览截图，未见横向溢出、文本遮挡或按钮截断。截图仅保存在忽略的 artifacts 中，不上传 GitHub。
- 所有浏览器测试使用独立临时 Profile 与本地合成页面；输入、点击和提交仅改变该测试页面的内存状态，不使用真实账号/客户站点。
- 真实配置位于仓库之外、权限 0600；测试结束删除临时浏览器 Profile；源码没有真实密钥。
- staged 扫描与 pre-commit hook 检查即将提交内容；CI 不需要真实密钥。
- 早期 live browser 探测存在未等待终态便退出的问题；改成明确状态轮询后完成闭环。未返回 usage 的中断尝试无法证明是否计费，不将成功两次的用量当作账户全部费用。

## 范围和剩余证据

- 当前实现顶层可见 DOM，不支持 iframe、Canvas、闭合 Shadow DOM、跨标签页任务或工具箱调用；完整清单继续保留。
- 当前新助手输出纯文本；旧 Markdown 渲染路径仍需独立安全加固，不宣称完成整个扩展的安全审计。
- storage.local 是浏览器本地明文配置，不是加密保险库；有本机访问权限的人仍可能读取。
- 脱敏规则不能识别全部业务机密，发送前预览必须保留。
- 停止不能撤销已经交给浏览器执行的动作；页面可以拒绝非可信 DOM 事件，此时需用户接管。
- 真实侧栏原生入口的不同 Chromium 品牌行为、商店包、无痕窗口专项兼容、真实站点表单未作破坏性验证。
