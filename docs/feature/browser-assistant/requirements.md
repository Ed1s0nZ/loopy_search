# 浏览器助手需求

- 状态：Implementation authorized；来自用户对完整功能池的直接实施授权，未声称本文已获逐条确认。
- 日期：2026-10-07。
- 优先级：浏览器助手第一，其他功能按 docs/roadmap.md 顺序交付。

## 用户场景与验收

| ID | 需求 | 可观察验收 |
| --- | --- | --- |
| BA-001 | 在当前浏览器提供自然语言任务入口 | 扩展弹窗可打开侧边栏，支持任务输入、页面预览、执行过程和最终回答 |
| BA-002 | 读取当前标签页 | 展示 URL、标题、可见正文、交互元素；浏览器内部页面明确报错 |
| BA-003 | 模型不执行任意代码 | 仅接受明确工具合同；非法动作、参数和外部脚本均拒绝 |
| BA-004 | 点击、输入、选择、滚动和导航 | 根据本次观察的元素标识操作，过期元素要求重新观察；导航仅允许 HTTP(S) |
| BA-005 | 只读和辅助执行模式 | 默认只读；辅助模式中的点击、输入、选择、导航都逐次确认；仅浏览器滚动无需修改确认 |
| BA-006 | 控制任务范围 | 固定目标标签页；起始站点范围明确；站点变化导致的内容发送需新的预览批准 |
| BA-007 | 随时停止、有限循环、失败恢复 | 停止中断模型请求和后续执行；步数与时间上限；失败可重新启动且无重复操作 |
| BA-008 | 敏感信息隔离 | 密码/敏感输入不观察、不填写；令牌和查询串等脱敏；密钥仅后台读取、仅发给用户配置的服务 |
| BA-009 | 模型上下文发送预览 | 用户在每个新站点查看脱敏页面快照、模型服务和任务后明确同意发送；页面内容不作为授权 |
| BA-010 | 任务轨迹 | 显示每一步工具、状态、结果；不把原始页面、输入值和凭据存入持久轨迹；关闭 UI 后停止 |
| BA-011 | 页面变化处理 | 每次动作前验证文档/元素快照；每次动作后重新观察；SPA 变化不会点击错位元素 |
| BA-012 | 本地配置 | 配置模型服务地址、模型和密钥；敏感字段不写入代码/日志/同步存储/Git；可删除密钥 |
| BA-013 | 兼容已有功能 | 保留划词、原弹窗、代理、请求与历史入口；旧 AI 客户端不再读取或传输密钥 |
| BA-014 | 无障碍和界面状态 | 键盘可操作、明暗主题、明确运行/确认/取消/完成/失败状态 |
| BA-015 | 验证和提交保护 | 自动测试工具合同、DOM、生命周期及真实扩展；提交和 CI 扫描敏感信息 |

## 默认选择及边界

- 根据“全部最佳实践完成”的授权采用保守默认：只读默认、所有页面写入逐次确认、HTTP(S) 页面、Chrome/Chromium 116+。
- 模型使用用户配置的 Chat Completions 兼容服务；没有配置时显示指引，不伪装执行成功。
- 初版实现本标签页 DOM 工具；跨标签页、视觉坐标、iframe、工具箱调用等仍在全量功能清单，后续交付，不删减最终目标。
- Canvas、跨域 iframe、闭合 Shadow DOM 与浏览器内部页面可能不可观察；展示覆盖范围。
- 本地密钥存储依赖浏览器本地环境，不声称加密保险库。
- GitHub 只提交源码、公开文档和合成测试数据；真实页面、账户、浏览器 Profile 和任务输出均不提交。

## 故障与恢复

权限不足：显示站点授权说明。模型错误：显示脱敏错误与重试入口。观察过期：不执行，重新观察。用户拒绝：停止任务。侧栏关闭或后台重启：任务停止，不自动恢复写入。模型建议危险动作：必须保持用户确认，不从网页文本接受新权限。
