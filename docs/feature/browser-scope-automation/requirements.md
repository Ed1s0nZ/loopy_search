# 浏览器范围与自动操作需求

状态：Implementation authorized（用户要求所有功能按最佳实践自主完成）；没有把本文声称为逐条确认过的快照。

| ID | 功能需求 | 验收 |
| --- | --- | --- |
| BSA-001 | 启动任务时选择初始页及可访问的其他标签 | 默认仅初始页；最多 8 页；公开 HTTP(S)，同窗口、同无痕环境；无效/跨环境拒绝 |
| BSA-002 | AI 列出及切换所授权的标签 | 模型只看到已选择的标签元数据；越权页不读取；新页面内容发送先预览批准 |
| BSA-003 | AI 创建与关闭标签 | 辅助/自动模式可提出，始终逐次确认；仅 HTTP(S) 新页；关闭仅所授权页，禁止关最后一个任务页 |
| BSA-004 | 自动模式连续处理已授权元素 | 用户在发送预览显式选定具体元素和 click/fill/select 操作；最多 8 次自动动作，默认 3 次；其余动作回到逐次确认 |
| BSA-005 | 自动授权只作用于同一文档、同一元素与描述 | 页面重载、标签切换、元素替换、按钮/表单目标变化后授权不能复用；重新预览并授权 |
| BSA-006 | 无内容即授权、无模型自授权 | 空授权等价逐次确认；模型不能提交 grant/权限参数；网页文本不能扩展范围或预算 |
| BSA-007 | 保留只读默认及原有接口 | 不提供新范围时仍单标签；不提供授权时原确认流程不变；旧划词和代理不改 |
| BSA-008 | 展示授权和剩余预算并允许撤销 | UI 显示当前任务页、范围、授权剩余次数；撤销立即影响后续自动动作；停止清除授权 |
| BSA-009 | 页面动作仍需观察与执行结果 | 自动动作也验证最新快照、目标可见性/敏感性；每动作后重新观察；不重复失败动作 |
| BSA-010 | 隔离测试与提交隐私 | 不调用真实账号页，不进行真实数据删除；测试使用本地 fixture、临时 Profile；真实密钥不进源码、截图、CI 或日志 |

## 默认选择

- 自动授权按当前页面的具体元素与工具授予，而非泛化为“整个站点任意操作”。导航、新开、关页不走自动授权。
- 授权按钮点击可能触发提交/删除/发送等业务行为，UI 明确提示，用户需选择确切目标；测试只覆盖合成站点。
- 标签切换改变助手的任务目标，不必改变浏览器焦点；视觉操作后续再定义焦点规则。
- 新打开的页面经一次确认后加入本次范围，发送页面内容仍需批准；不自动关闭任务结束时的页面。
- 无痕任务不能读取普通窗口的标签或反之；持久配置的无痕专项隔离在 TRUST-13，不能据此标全量完成。
- 截图/视觉、iframe/Shadow DOM、工具箱调用和回放仍在完整路线，不从目标中删减。
